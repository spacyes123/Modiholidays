Package Editor

Manage packages, sightseeing days, hotels, inclusions and exclusions. This is a local editor, not an online password-protected admin dashboard. Do not publish this page as a secure backend.

Changes stay in your browser until you save. Use Save to selected JSON file (Chrome on desktop) or Download updated packages.json. Then run python3 build_site.py to regenerate SEO pages before uploading to GitHub. No package prices are displayed publicly.
